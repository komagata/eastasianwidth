## 0.2.0 package notice

The 0.2.0 package corresponds to commit [`b89f04d44dc786885615e94cd6e2ba1ef7866fa4`](https://github.com/komagata/eastasianwidth/blob/b89f04d44dc786885615e94cd6e2ba1ef7866fa4/package.json). Its `package.json` declares `"license": "MIT"`, but its published tarball did not include a license notice.

The maintainer's complete MIT notice for version 0.2.0 is preserved in [MIT-LICENSE.txt at commit 1d41951a59d63fb2d77cda021050fc070cae424a](https://github.com/komagata/eastasianwidth/blob/1d41951a59d63fb2d77cda021050fc070cae424a/MIT-LICENSE.txt). Its exact copyright line is `Copyright komagata`, with no year. This full notice was added to the repository in 2024, when the package was version 0.3.0.

## Original author's permission and attribution

On 2026-10-23, the original author confirmed by email that permission for eastasianwidth had previously been given in comments and that the existing package, including all previously published versions, may continue to be distributed unchanged. No additions to those old versions are required.

The author's [original article](https://takenspc.hatenadiary.org/entry/20111126/1322252878) publicly records the individual permission given to eastasianwidth. It separately offers the article's code under the MIT license for new uses.

The author recommended adding `Copyright (c) 2011 takenspc`, and that attribution has been adopted in the current package notice. This was a recommendation, not a new condition imposed on already-published versions of eastasianwidth.
